## [1.1.0] - 2026-06-15

### Added
- Expenses management module featuring full CRUD operations, list filtering, and monthly expense analytics.
- PDF template settings configuration page with live preview capabilities.
- Customizable print layouts for service orders, allowing customization of company branding, colors, and layout options.
- Collapsible sidebar navigation for improved screen space.
- CSV import and export functionality for expenses data.
- Options to hide labor price and individual item prices in customer-facing invoices.

### Fixed
- Expense lists now display dates consistently in `dd/mm/yyyy` format.
- Resolved minor settings synchronization issues.

## [1.0.0] - 2026-05-01

### Added
- Initial release of MechanicPro desktop management application.
- Core management modules for Clients, Vehicles, and Service Orders.
- Shop Dashboard summarizing key performance metrics and indicators.
- CSV import and export capabilities for clients and vehicles.
- PDF generation utility for professional service invoices.
- Technical report and user manual documents.
