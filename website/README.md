# MechanicPro Publicity Website

This is the static landing page for [MechanicPro](https://github.com/eduardofreitasf/MechanicPro), the ultimate desktop management system for mechanic shops built with Tauri and React.

## Overview

This website serves as the publicity and download page for the MechanicPro application. It highlights the main features of the desktop app, displays UI mockups, and provides links to the project's source code and latest releases.

## Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Custom CSS** (Modern dark-mode aesthetic with glassmorphism and micro-animations)

## Development

To run the website locally:

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.

## Formatting

This project uses Prettier for code formatting. You can format the code by running:

```bash
npm run format
```

## Deployment

This website is configured to be hosted for free on **GitHub Pages**.

To deploy the website:

```bash
npm run deploy
```

This command will build the static files to the `dist` folder and push them automatically to the `gh-pages` branch, making the site live on GitHub Pages.
